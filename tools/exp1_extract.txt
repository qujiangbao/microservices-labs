任务① 父子工程创建与Nacos实践
（1）创建Maven父子聚合工程 
（2）服务提供者注册到Nacos
（3）服务消费者发现并调用服务 
（4）Nacos控制台管理
详细实验步骤：
步骤1：先创建父工程，配置pom.xml文件以管理公共依赖和版本。
<?xml version="1.0" encoding="UTF-8"?>
<project xmlns="http://maven.apache.org/POM/4.0.0"
         xmlns:xsi="http://www.w3.org/2001/XMLSchema-instance"
         xsi:schemaLocation="http://maven.apache.org/POM/4.0.0 http://maven.apache.org/xsd/maven-4.0.0.xsd">
    <modelVersion>4.0.0</modelVersion>

    <groupId>cn.js.ccit</groupId>
    <artifactId>unit2Demo1-nacos-discovery</artifactId>
    <version>1.0-SNAPSHOT</version>

    <modules>

        <module>service-provider</module>
        <module>service-consumer</module>
    </modules>

    <packaging>pom</packaging>


    <dependencyManagement>
        <dependencies>
            <!--spring boot 2.6.3-->
            <dependency>
                <groupId>org.springframework.boot</groupId>
                <artifactId>spring-boot-dependencies</artifactId>
                <version>2.6.3</version>
                <type>pom</type>
                <scope>import</scope>
            </dependency>

            <!--spring cloud 2021.0.1-->
            <dependency>
                <groupId>org.springframework.cloud</groupId>
                <artifactId>spring-cloud-dependencies</artifactId>
                <version>2021.0.1</version>
                <type>pom</type>
                <scope>import</scope>
            </dependency>

            <!--spring cloud Alibaba 2021.0.1.0-->
            <dependency>
                <groupId>com.alibaba.cloud</groupId>
                <artifactId>spring-cloud-alibaba-dependencies</artifactId>
                <version>2021.0.1.0</version>
                <type>pom</type>
                <scope>import</scope>
            </dependency>
            
        </dependencies>
    </dependencyManagement>

</project>

步骤2：分别创建2个子模块（微服务），服务提供者（service-provider）和服务消费者（service-consumer）。
步骤3：在上述两个微服务的pom.xml文件中配置Nacos服务注册与发现组件和web的依赖。
<!--nacos discovery 服务发现依赖-->
<dependency>
    <groupId>com.alibaba.cloud</groupId>
    <artifactId>spring-cloud-starter-alibaba-nacos-discovery</artifactId>
</dependency>

<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
</dependency>

Tips：由于此时我们还没有学Feign或者Dubbo的方式（均会在第三单元讲解）来让微服务之间简便地发起服务调用，因此消费者微服务service-consumer需要使用Spring自带的发起HTTP的客户端工具类RestTemplate，因此就需要配合使用客户端的负载均衡，因此在消费者微服务的pom.xml中需要额外再加上这个做客户端负载均衡的依赖。
<!--服务负载均衡依赖-->
<dependency>
    <groupId>org.springframework.cloud</groupId>
    <artifactId>spring-cloud-loadbalancer</artifactId>
</dependency>

步骤4：在上述两个微服务的业务全局配置文件application.yaml中配置Nacos服务器地址及应用名称。
步骤5：在以上两个微服务分别定义出controller中的方法，并使用Spring内置的HTTP客户端类（即RestTemplate，其中提供一些通用的方法，比如：restTemplate.getForObject(调用的微服务URL + 接口地址，responseType.class)，可简便地实现HTTP接口的调用），让service-consumer微服务的接口调用service-provider微服务的接口完成对应需求。
Tips1：这里定义的方法的编码要求是：这个方法需要返回String类型的字符串，这个字符串是这样一句话，“当前是”+ “你自己的名字” + “在工作，我的端口号是”+ 当前服务的端口号。例如：“当前是林卓凡在工作，我的端口号是8080”。
Tips2：由于SpringBoot框架中没有主动注入RestTemplate对象，所以引提前在service-consumer微服务中提前创建出一个配置类，并在类中使得Spring容器中有RestTemplate的Bean对象。


步骤6：启动项目的这两个微服务（启动之前必须要有对应的SpringBoot的标准启动类并加上对应的开启服务注册发现的注解@EnableDiscoveryClient，这是非常基础的知识点，故这里不贴代码了），在浏览器访问Nacos控制台管理页（http://localhost:8848/nacos，默认账号密码均为nacos），测试验证这两个微服务是否分别都成功注册至其中。
步骤7：在浏览器发送一个请求（比如：http://localhost:端口号/XXX方法的路径），访问服务消费者（即service-consumer微服务）的XXX方法，以测试验证其是否能够调用service-provider微服务的接口并在浏览器页面端打印相应的输出语句。

步骤5：创建ServiceConfigController，写上一个方法输出Nacos配置中心保存的配置信息。
@RefreshScope // 这个注解支持配置的自动更新。
// 作用：当Nacos配置中心修改了某配置的值，程序可以自动感知并更新对应的变量的值
@RestController
public class ServiceConfigController {

    @Value("${service.config}")
    private String serviceConfig;

    @GetMapping("/service/config")
    public String getConfig() {
        return serviceConfig;
    }
}
