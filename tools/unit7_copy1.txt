Sentinel概述Sentinel是阿里巴巴开源的微服务流量控制组件，面向分布式服务架构，提供流量控制、熔断降级、系统负载保护等功能。Sentinel以流量为切入点，帮助微服务系统保障稳定性。Sentinel具有以下特征：（1）轻量级，核心库无多余依赖；（2）丰富的应用场景，在阿里巴巴覆盖了双十一等核心场景；（3）提供实时的监控和动态规则配置能力；（4）支持多种流量控制策略，如QPS限流、热点参数限流、系统保护等。4.2  Sentinel核心概念资源（Resource）：Sentinel保护的对象，可以是Java方法、字符串、API接口等。在Sentinel中，每个资源对应一个监控指标。规则（Rule）：定义如何保护资源的策略，包括流控规则（FlowRule）、熔断规则（DegradeRule）、系统保护规则（SystemRule）等。流控（Flow Control）：根据QPS、线程数等指标控制流量，防止系统被瞬时大流量冲垮。熔断降级（Circuit Breaking）：当检测到某个资源的响应时间过长或异常比例过高时，暂时切断对该资源的调用，快速失败。系统保护（System Protection）：从系统整体维度进行保护，根据系统负载、CPU使用率、总体QPS等指标进行保护。4.3  Sentinel+Gateway集成Sentinel可以与Spring Cloud Gateway集成，在网关层实现流量控制。通过在Gateway中引入sentinel-gateway依赖，可以对路由进行限流和熔断保护，保障后端微服务的安全。实验内容：本实验以SweetFlower微服务项目为基础，学习Sentinel的安装配置和使用方法。实验包含以下任务：搭建Sentinel环境、配置QPS限流规则、配置热点参数限流、配置系统保护规则。任务1 当成自己的参数。控制台默认就是 8080，不需要再写这个参数。解决：改成 cmd /c java -jar sentinel-dashboard-1.7.0.jar。日志里 Tomcat 端口是 8080，页面能打开。错误2：应用启动后，控制台里过一会儿才出现 service-sentinel，而且机器端口不是 8719。分析：客户端默认懒连接，要先访问一次接口才发心跳。8719 被控制台进程占用，客户端改用 8720。解决：先请求 http://localhost:8089/hello?name=test，等两三秒再刷新。左侧显示 service-sentinel (1/1)，机器是 10.26.144.55:8720。错误3：热点规则加上之后，type=a 一开始全部通过。分析：spring-cloud-starter-alibaba-sentinel Sentinel的QPS限流和热点参数限流有什么区别？分别适用于什么场景？答：QPS 限流按整个资源计数，不区分参数。/hello 的阈值是 1 之后，name 无论是什么，同一秒里多出来的请求都是 429。热点参数限流只统计指定下标的参数。hotpoint 的参数索引 0 是 type，阈值 10。type=a 打到 24 次时只有 10 次通过，type=b 的 8 次全部通过。接口总容量用 QPS。商品 id、用户 id 这种少数值特别热、其他值还要正常访问的时候用热点参数。2. 系统保护规则中的LOAD、RT、QPS三个指标分别代表什么含义？如何合理设置阈值？答：LOAD 是系统近一分钟的平均负载，超过就拒绝新请求，这次填的是 2。这台机器是 Windows，JDK 的 getSystemLoadAverage 经常返回 -1，所以这条在 Windows 上基本不会触发，Linux 上可以按 CPU 核数的大约 0.7 到 1 倍来设。RT 是入口的平均响应时间，单位毫秒，这次是 100，要高于接口平时的耗时，低于能接受的超时。QPS 是整台机器每秒的入口请求数，这次是 5。TestThread 用 10 个线程打 50 次 /hi，5 次打印 hi，45 次是 429。三个条件满足任意一个就会拦截，阈值按压测容量留出余量，不要顶满。3. 在实际生产环境中，如何根据业务需求选择合适的限流策略？答：先看要保护的是哪一层。接口总流量用 QPS，可以直接失败，也可以排队把突发摊开。某个参数特别热就用热点参数，必要时给个别参数值单独设阈值。下游变慢或错误变多用熔断。这次 RT 阈值 100 毫秒，接口自己 sleep 了 200 毫秒，慢调用堆起来之后，下一次请求 2 毫秒就返回 429，不再等这 200 毫秒。机器本身快被打满时用系统规则兜底，LOAD、平均 RT 和入口 QPS 可以一起配。顺序一般是先按业务接口限流，再给不稳定的依赖做熔断，系统规则放在最后。阈值从压测和监控里来，再跟着实时监控调整。指导教师评语：1.实验态度（20分）□优秀：实验态度严谨认真，积极投入，严守纪律，预习准备充分完备。（18分及以上）□良好：实验态度端正，主动配合实验，遵守规范，预习准备较为充分。（16-17分）□合格：实验态度基本端正，能完成实验，无违纪，预习准备基本到位。（12-15分）□待改进：实验态度不够认真，准备不足，纪律意识有待加强。（11分及以下）2.操作能力（40分）□优秀：实验步骤规范无失误，仪器使用熟练，独立动手能力突出。（36分及以上）□良好：实验步骤规范，核心操作无误，仪器较熟练，可独立完成主要环节。（32-35分）□合格：实验步骤基本规范，偶有细节失误，需少量指导完成实验。（24-31分）□待改进：实验步骤不规范，操作失误较多，仪器生疏，独立操作能力较弱。（23分及以下）3.实验报告规范与质量（30分）□优秀：报告格式规范，数据完整准确，结论科学合理，书写整洁。（27分及以上）□良好：报告格式规范，数据完整，分析合理清晰，结论正确无误。（24-26分）□合格：报告格式基本规范，数据无缺失，分析合理，存在少量细节错误。（18-23分）□待改进：报告格式混乱，数据错漏，分析逻辑不清，结论缺乏依据。（17分及以下）4.创新表现（10分）□优秀：主动优化实验思路，有创新改进，自主拓展，探究意识极强。（9分及以上）□良好：能结合理论思考，有一定探究行为，在基础上略有拓展。（8分）□合格：严格按要求完成实验，无创新拓展，扎实完成既定实验目标。（5-7分）□待改进：仅被动完成实验，无自主思考，缺乏探究与创新意识。（4分及以下）实验成绩评定：      指导教师（签名）：      日期：2026年 9月30日
